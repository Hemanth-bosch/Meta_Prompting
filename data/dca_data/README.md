# DCA Dataset

The DCA image-pair dataset. **Not committed to git** — download `dca_data.zip` from SharePoint and extract it here.

```
data/dca_data/
├── image_pairs/                    # Pair folders (pair_001, ...) — each holds original + reimage images
├── image_pairs_llm_output_exp1/    # Pair-level ground-truth JSONs (pair_NNN.json)
└── human_label_stats/              # Category-distribution stats (version-controlled)
```

The dataset contains **429 image pairs**: 376 original pairs from the source repository and 53 synthetic pairs (pair_377–429) generated by `utils/dca_data_generation/augment_rare_categories.py` to address class imbalance in categories B1, B2, and B4. Each JSON includes a `doubt` field (`true` for 25 uncertain pairs) and `human_label_category` for stratified splitting.

See [../README.md](../README.md) for the ground-truth JSON schema and per-directory sizes.

## Loading

```python
from utils import load_dca_dataset

# Reads image_pairs/ + image_pairs_llm_output_exp1/
dataset = load_dca_dataset()
```

Paths default to the above and can be overridden via `.env` (`DCA_IMAGE_PAIRS_DIR`, `DCA_GT_DIR`).
