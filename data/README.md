# Data Directory

The DCA dataset goes here locally. **It is not committed to this repository** — download `dca_data.zip` from SharePoint and extract it into `data/dca_data/`.

```
data/
└── dca_data/
    ├── image_pairs/                    # Pair folders (pair_001, pair_002, ...) with original/reimage images
    ├── image_pairs_llm_output_exp1/    # Pair-level ground-truth JSONs
    └── human_label_stats/              # Category-distribution stats (version-controlled)
```

## Download

Download the archive from [SharePoint](https://bosch.sharepoint.com/:u:/r/sites/msteams_215d00ea/Shared%20Documents/Data/Meta%20Prompting%20Use%20Cases/dca_data.zip?csf=1&web=1&e=nyNG5a) and extract it into `data/dca_data/`. After extraction, the loader expects `data/dca_data/image_pairs/`, `data/dca_data/image_pairs_llm_output_exp1/`, and `data/dca_data/human_label_stats/`.

The dataset contains **429 image pairs**: 376 original pairs from the source repository and 53 synthetic pairs (pair_377–429) generated by `utils/dca_data_generation/augment_rare_categories.py` to address class imbalance in categories B1, B2, and B4. Each JSON includes a `doubt` field (`true` for 25 uncertain pairs, `false` otherwise) and `human_label_category` for stratified splitting.

## Ground-truth JSON schema

Each file in `image_pairs_llm_output_exp1/` is named `pair_NNN.json`:

```json
{
  "pair_id": "pair_001",
  "discard_image": false,
  "changes": "The header text changed from 'Rev A' to 'Rev B'. Component C3 was removed.",
  "human_label_category": "B3",
  "doubt": false
}
```

| Field | Type | Description |
|-------|------|-------------|
| `pair_id` | string | Matches the `image_pairs/pair_NNN/` folder name |
| `discard_image` | bool | `true` if the pair should be discarded (no meaningful change or non-informational) |
| `changes` | string | Human-written description of meaningful visual/content differences |
| `human_label_category` | string | Category code: `A1`, `A2`, `B1`, `B2`, `B3`, `B4`, `B5a`, `B5b` — used for stratified splitting |
| `doubt` | bool | `true` for 25 ambiguous pairs reviewed by multiple annotators |

## Approximate sizes

| Directory | Contents | Approx. size |
|-----------|----------|-------------|
| `dca_data/image_pairs/` | 429 pair folders, 2 images each (JPEG/PNG, ~200–800 KB per image) | ~400 MB |
| `dca_data/image_pairs_llm_output_exp1/` | 429 JSON files (~1 KB each) | ~1 MB |

## Loading

```python
from utils import load_dca_dataset

# Reads data/dca_data/image_pairs/ + data/dca_data/image_pairs_llm_output_exp1/
dataset = load_dca_dataset()
```

Paths default to the above but can be overridden via `.env` (`DCA_IMAGE_PAIRS_DIR`, `DCA_GT_DIR`).
