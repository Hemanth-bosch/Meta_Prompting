# Data Directory

Place datasets here locally. 
- **Yanase**: YANASE/, YANASE_images/, YANASE_ground_truth/
- **Japanese Order**: png/, json/
- **DCA**: dca_data/ (download `dca_data.zip` from SharePoint and extract it here)

```
data/
├── YANASE/                  # Raw order PDFs
├── YANASE_images/           # Rendered page PNGs (from PDFs)
├── YANASE_ground_truth/     # Curated ground truth JSONs
├── dca_data/
│   ├── image_pairs/         # Pair folders (pair_001, pair_002, ...) with original/reimage images
│   └── image_pairs_llm_output_exp1/  # Pair-level JSON outputs used in baseline experiments
├── png/                     # Japanese order images
└── json/                    # Japanese order ground truth
```

## DCA note

DCA data is not committed to this repository. Download the archive from [SharePoint](https://bosch.sharepoint.com/:u:/r/sites/msteams_215d00ea/Shared%20Documents/Data/Meta%20Prompting%20Use%20Cases/dca_data.zip?csf=1&web=1&e=nyNG5a) and extract it into `data/dca_data/`.

After extraction, the loader expects the usual `data/dca_data/image_pairs/`, `data/dca_data/image_pairs_llm_output_exp1/`, and `data/dca_data/human_label_stats/` directories.

The dataset contains 429 image pairs: 376 original pairs from the source repository and 53 synthetic pairs (pair_377–429) generated by `utils/dca_data_generation/augment_rare_categories.py` to address class imbalance in categories B1, B2, and B4. Each JSON includes a `doubt` field (`true` for 25 uncertain pairs, `false` otherwise) and `human_label_category` for stratified splitting.

## Loading

```python
from utils import load_yanase_order_dataset, load_japanese_order_dataset

# YANASE — reads from YANASE_images/ + YANASE_ground_truth/
dataset = load_yanase_order_dataset()

# Japanese orders — reads from png/ + json/
dataset = load_japanese_order_dataset()
```

Paths default to the above but can be overridden via `.env` (see the env-vars section in the root README).
