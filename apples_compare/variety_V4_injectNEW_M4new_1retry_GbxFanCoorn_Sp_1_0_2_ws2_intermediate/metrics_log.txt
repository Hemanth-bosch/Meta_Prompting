Srv\_Debounce debounces a toggling boolean input signal and returns the debounced state of the signal as boolean value.  
This function is used to debounce a digital input signal by separate high to low and low to high debounce times

| Hint |
| --- |

This class does not contain sequence numbers for the class methods.
