Srv\_Debounce

Srv\_Debounce debounces a toggling boolean input signal and returns the debounced state of the signal as boolean value.  
This function is used to debounce a digital input signal by separate high to low and low to high debounce times

| Hint |
| --- |
| Each function call calculates a new debounce timer value and thus result might be wrong if called not exactly once per process call.  This class does not contain sequence numbers for the class methods.  The out value has to be connected to a variable to compute the class.  if the output is used in multiple places, there is a risk that the class output might be calculated twice. To avoid this use a process local variable at the output of the class(incase output is used in multiple places). |
