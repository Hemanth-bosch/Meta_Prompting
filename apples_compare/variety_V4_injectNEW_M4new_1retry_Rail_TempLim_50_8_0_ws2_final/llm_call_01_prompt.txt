Srv\_RampSwitch

This function ramps a signal between two target values, based on a switch value.  
When switch is "TRUE(1)", the function ramps the signal from target B to target A.  
When switch is "FALSE(0)",the function ramps the signal from target A to target B.

The current state value and the target value will be selected by the functionality, only if there is a transition of switch  
  
If the ramp has reached  destination and no change of switch occurs, the output value of SrvX\_RampSwitch follows the target vaue

Example Implementation:

Methods:

| Method | Description |
| --- | --- |
| active | This method is used to determine if the ramp is ramping |
| out | Calculates the ramp value and returns the result on the outport. |
| init | This method is used to set the switch (Determines which of the 2 targets shall be used) |
| pos | Input Value for a bit of the memory element 'Flag' |
