## Validated test guidelines for MoFSrv_Lib_RampEnhd_Out (newKB) — cover these scenarios:
1. Checking the correct initialization of the ramp — Initialize the Ramp; Check: Output = initialization value
2. Checking the slope up (with several SLOPE UP between null and MAX) — Set the input value to a defined value; Wait: Output value = Input value; Change the input value to a higher value; Check: Output value = Output value ramps from start value to end value with the correct SLOPE UP; Wait: Output value = Input value
3. Checking the slope down (with several SLOPE DOWN between null and MAX) — Change the input value to a lower value; Check: Output value = Output value ramps from start value to end value with the correct SLOPE DOWN; Wait: Output value = Input value
4. Checking the ramp in case of abortion — Change the input value to a higher value; Check: Output value = Output value ramps from start value with the correct SLOPE UP; Change the input value to a lower value before output value reaches the end of the ramp; Check: Output value = Output value ramps from intermediate value with the correct SLOPE DOWN; Change the input value to a higher value before output value reaches the end of the ramp; Check: Output value = Output value ramps from intermediate value with the correct SLOPE UP
